## Family notes

ROUTE MAP / DELEGATION. `/signals` renders `<SignalsHub />` (10-line page). `/signals/alpha-picks` renders `<SignalsHub initialHorizon="swing" />`, `/signals/momentum-picks` renders `<SignalsHub initialHorizon="momentum" />`, `/signals/index-momentum-30` renders `<SignalsHub initialHorizon="momentum30" />` — all 6-line files. IMPORTANT AS-BUILT CORRECTION to the brief: `/signals/swing` and `/signals/momentum` are NOT category pages — they are 6-line server files that call `redirect()` to `/signals/alpha-picks` and `/signals/momentum-picks` respectively, so they render no UI at all. There are exactly THREE distinct signal-hub screens plus the detail page.

ONE SHELL, ONE TAB STRIP. SignalsHub mounts EXACTLY ONE AppShell for the whole hub; `CategorySignalsPage` is passed `embedded` so it drops its own AppShell AND its '← Signals' breadcrumb. Tab switching uses `router.replace(pathname or pathname?horizon=…, {scroll:false})` on the SAME path — no route remount, one AppShell for the session. `useSearchParams` is read inside a `<Suspense>` whose fallback is the same presentational `HubContent`, so the tab strip never flashes. URL is source of truth: `?horizon=` wins when it parses, else the route's own default; selecting the route's own default drops the query for a clean canonical URL.

THE momentum30 STRUCTURAL QUIRKS (verify before redesigning). SignalsHub's `HORIZONS`/`TABS` arrays contain only `all | swing | momentum`, so on `/signals/index-momentum-30` (a) the tab strip renders with NO active pill, and (b) `?horizon=momentum30` is rejected by `isHorizon` and falls through to the route default. Separately, `categoryOf()` can only return `'swing' | 'momentum'`, and `momentum30` subscribes to neither the momentum nor the swing-ML endpoint — so BOTH its Opening and Closed lists are permanently empty, and its Model Book renders a 4-row short form with Key Reads at 3 tiles. A redesign should either wire a fourth tab + data source or treat this route as an explainer page.

SHARED LAYOUT PRIMITIVES. AppShell: fixed 240px (68px collapsed, persisted in localStorage `quantx.sidebar.collapsed.v2`) left sidebar on bg-wrap; fixed 72px right icon rail on bg-main; main pane `lg:ml-60/lg:ml-[68px] lg:mr-[72px]`, inner `mx-auto max-w-[1440px] px-4 md:px-6`; mobile-only Topbar below lg opening MobileDrawer; ⌘/Ctrl+K CommandPalette (which lists Signals, Alpha Picks, Momentum Picks, Swing signals, Momentum signals, Index Momentum 30); ComplianceFooter on every authed surface. Book pages add a second, tighter cap of `max-w-7xl` (1280px). The sticky tab strip is `top-0 z-20` and goes full-bleed with `-mx-4 md:-mx-6`.

SHARED COMPONENTS ACROSS THE GROUP. `components/signals/categories.ts` is the single copy source: it defines the three `SignalCategory` records (id/slug/label/title/hold/tagline/icon/whatIs/howAI[]/engines[]/holdDays/faq[]), a `FAQ_COMMON` trio appended to every book's FAQ, the `normalize()` API→DisplaySignal mapper, `categoryOf()`, `isOpen`/`isClosed` status sets, `MIN_SAMPLE = 8` and `computeStats()`. `CATEGORY_LIST` exports only `[swing, momentum]` — which is why the Overview 'By horizon' card shows two rows and the horizon Select offers two options. `SignalCard` + `expectedMovePct`/`riskPct` are shared by the books and the Overview blotter. `FaqAccordion` is used by all three books.

HONESTY / COMPLIANCE INVARIANTS ENCODED IN THE UI (do not design these away). (1) No win rate or annualised return renders anywhere in this group until MIN_SAMPLE=8 decided trades — every book links to `/proof?tab=track-record` instead. (2) The Key Reads strip is 'always-on coverage/freshness' — never a blank stat, never a fabricated performance number; extra tiles only append when the paper-window API actually returns them. (3) The Model Book quotes the FROZEN walk-forward backtest and labels its provenance. (4) 'Best R:R' was deliberately dropped from the Overview because leading with the single most favourable row is a return-claim pattern. (5) Only public engine names ever ship — Alpha, Mood, Regime, Counterpoint, AutoPilot — never model architectures. (6) DisclaimerFooter + ComplianceFooter (the 'not a SEBI-registered Research Analyst' block) must survive any redesign.

TWO-STEP MONEY RULE. Every live-order path in this group requires QuickTrade (collect) → ConfirmDialog (deliberate confirm, with Cancel taking initial focus) → API. This applies to the Overview's 'Trade' button and to the detail page's 'Live trade'. Paper trading (virtual ₹10L book) is single-step, free and needs no broker.

DESIGN-SYSTEM DRIFT WORTH KNOWING. Radius usage inside this group is not uniform: SignalCard is `rounded-md` (12px), CategorySignalsPage's stat tiles and hero panel are `rounded-lg` (16px), DataTable and level tiles are `rounded-sm` (8px), and detail-page chips are `rounded-xs` (6px). The `Skeleton` component's ROUNDED map sends both `sm` and `lg` to 8px, so `rounded="lg"` skeletons are NOT 16px. Legacy class names persist with new meanings: `.glass-control*` and `.lg-surface` are now SOLID opaque surfaces (no blur) — only `.glass-float`/`.glass-pill` still blur. `.trading-surface` = bg-wrap + 1px line + 12px radius + elev-1 + 20px padding. `.heading-display` resolves to Geist (not Bricolage, despite the comment) at weight 600 / -0.02em.

MOTION. Reveal = opacity 0→1 + y 10→0 over 0.45s cubic-bezier(.16,1,.3,1) with per-item delays (0.03–0.08s, capped at 6 items). Tab crossfade = 0.18s easeOut, disabled under prefers-reduced-motion. `.lift` = translateY(-3px) over 0.26s plus a border-colour shift to the accent at 34%. The FAQ uses a grid-rows-[0fr]→[1fr] height transition over 300ms ease-out. The only infinite animations in the group are the ThinkingLine dot, the loading skeleton pulse and the error-boundary ring.
