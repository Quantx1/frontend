## Family notes

All six components are dark-first and re-theme purely through CSS variables (tailwind.config.ts maps every semantic class to rgb(var(--rgb-*)) channels; globals.css :root = dark, .light = the daylight register), so each hex below has a light twin: #0D0D0E→#EDF1F4, #151517→#FFFFFF, #1E1E21→#F4F7F9, #29292D→#DDE5ED, #3B3B40→#C8D4DE, #F7F7F8→#1D1D1D, #D3D3D7→#4D585F, #96969E→#5F6B75, #8FB0FF→#3459C9, #10B981→#0A6B50, #F5808C→#B81C22, #F0A94F→#9A4D00; #406AE4 (accent FILL) is identical in both.

RADIUS AS-BUILT: Tailwind is remapped to xs 6 / sm 8 / md 12 / lg 16 / full 9999. So `rounded-md` on a card = 12px and `rounded-lg` = 16px. The two foundation-Card cards (FusionVerdictCard, AITradeDeskCard) are 12px; the four hand-rolled cards (AIDossierPanel, ProbabilityCard, TabAiRead, WhyMovingCard) are 16px — an as-built inconsistency, not a rule.

TOKEN ALIASES USED HERE: bg-wrap = card #151517; bg-main = page canvas #0D0D0E (used as an INSET well inside the dossier card); bg-surface-2 / bg-wrap-hover = #1E1E21; border-line ≡ border-d-border = #29292D; text-d-text-primary/secondary/muted = #F7F7F8 / #D3D3D7 / #96969E; text-primary and text-ai both resolve to the accent INK #8FB0FF (textColor.primary is deliberately remapped away from the #406AE4 fill), while bg-primary stays the #406AE4 FILL; text-success/danger/warning = #10B981 / #F5808C / #F0A94F, i.e. the P&L triplets reused as verdict tone; text-highlight = #F0A94F.

TYPE AS-BUILT vs the system: these cards predate the v6 role scale and use arbitrary pixel sizes almost everywhere — 8, 9, 9.5(none), 10, 11, 11.5, 12, 12.5, 13, 14, 18, 20, 24px. Sizes below the documented 11px floor appear in three places: the 9px mono eyebrows/footnotes throughout AIDossierPanel, and the 8px 'Active now' pill in ProbabilityCard. Numerics use the `.numeric` utility (Geist Mono + tabular-nums + −0.01em) except FusionVerdictCard's composite, which renders in the sans face.

SHADOWS/BLUR: none of the six uses a shadow or a blur. All are opaque surface-step + hairline, per the card recipe. Nested content uses `bg-main` wells (dossier) rather than the documented `.panel-inset`.

DATA/COST MODEL: the three cheap cards load on mount (AIDossierPanel via SWR 120s dedupe + 3 retries, FusionVerdictCard via SWR 120s, ProbabilityCard via a raw useEffect); the two expensive ones are click-gated (AITradeDeskCard 'Generate deep read', WhyMovingCard 'Ask AI'), and TabAiRead loads lazily with its tab. Every LLM read is cached server-side per symbol/day. Three of the six fail by disappearing entirely (ProbabilityCard, TabAiRead return null; WhyMovingCard collapses to one honest line) — only AIDossierPanel renders a real error state, in #F5808C.

MISSING TOKEN (real defect worth reproducing faithfully or fixing): AITradeDeskCard's evidence chips use `bg-d-bg-subtle`, which is not defined in tailwind.config.ts or globals.css (also used in TechnicalsPanelCard.tsx:261). No background rule is generated, so the chips render transparent over the card fill with only their #29292D hairline.

HEADER-SLOT QUIRK: AITradeDeskCard passes its 'Deep reasoning · cached for today' meta as a second child of <CardHeader> rather than through the `action` prop, so it is NOT right-aligned — it flows inline immediately after the title with no separating space.

PAGE CONTEXT: all six live on /stock/[symbol] (app/stock/[symbol]/page.tsx), every one behind a dynamic import with ssr:false and its own ErrorBoundary. Order: 520px TradingView chart → AITradeDeskCard (full-width hero) → the 'AI engines read {symbol}' Tabs block with three panels — Engine Read (TabAiRead + FusionVerdictCard | AIDossierPanel in lg:grid-cols-2, then TechnicalsPanelCard, then a lg:grid-cols-3 row, then ChartVisionCard), Why It Moves (TabAiRead + WhyMovingCard + NewsIntelligenceCard), Forecast (TabAiRead + ProbabilityCard | EarningsPreviewCard in lg:grid-cols-2).
