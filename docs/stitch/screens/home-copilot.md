## Family notes

SHELL. Every screen here except `/` renders inside `app/(platform)/layout.tsx` → `AppShell` (components/shell/AppShell.tsx): a fixed LEFT Sidebar (w-60 = 240px expanded, w-[68px] collapsed, persisted in localStorage 'quantx.sidebar.collapsed.v2', bg-wrap, border-r border-line, hidden below lg), a fixed RIGHT icon rail (72px, aria-label "Utilities", bg-main, desktop only), and a MAIN pane with lg:ml-60 / lg:ml-[68px] + lg:mr-[72px] whose inner content is `mx-auto w-full max-w-[1440px] px-4 md:px-6`. Below lg the rails vanish and a mobile Topbar (h-14 = 3.5rem) opens a MobileDrawer. A skip-to-content link is the first focusable element. ⌘/Ctrl+K opens CommandPalette; Esc closes palette + drawer. `ComplianceFooter` is appended inside the same 1440px box on EVERY authed surface. The group layout also mounts `SystemHaltBanner` (dynamic, ssr:false) above the shell and `AutopilotStickyStop` (mobile-only, renders only when AutoPilot is enabled) below it, and runs three side-effects: an onboarding check that replaces the route with /onboarding/broker-connect when onboarding is incomplete, referral attribution from localStorage 'pending_ref', and Web Push subscription setup.

SIDEBAR ↔ COPILOT CONTRACT. The sidebar is the thread list for this route group: it SWRs 'copilot:conversations', renders a 'New Chat' link to /copilot and a Recent list whose items navigate to /copilot?c=<id>; deleting the open thread pushes back to /copilot. The copilot page mutates that same SWR key on save, and the dock's "Maximize" pushes /copilot?c=<id>. The brand lockup in the sidebar (and in HomeFooter) links to /copilot, i.e. /copilot is treated as home everywhere.

DEAD CODE WARNING (important for a redesign). Roughly 115 lines of app/(platform)/copilot/page.tsx render a signed-out marketing home — a MarketTicker strip, an "Explore Quant X" 42px display heading, a 3-up image-topped FEATURE_CARDS wall (Alpha Picks / Momentum Picks / AI Scanner / AI Algos / AutoPilot with an "Elite" warning badge, each with a 112px webp media band, a category eyebrow, a 22px display title, a 12.5px blurb and a "See More →" affordance), a `FeatureMotif` SVG family (candles / sparkline / scan / gauge / flow / pilot), a gated track-record band (4 Stat tiles + a 520x88 Sparkline + "Cumulative return · 90d") and a DisclaimerFooter. NONE of it renders: `if (signedOutHome) return <spinner>` returns earlier, so by the time the ternary is evaluated `signedOutHome` is always false. Skeleton is an entirely unused import; Badge, Sparkline and DisclaimerFooter are imported only for that branch. Do not carry any of it into a redesign without a product decision to revive the signed-out home.

DESIGN INVARIANTS THAT SHAPE EVERY COPILOT SURFACE. (1) One card per turn, hard cap — `lib/copilot/one-card.ts` picks entity > strategy > first stub-able, everything else collapses to a DataStub, and no table is ever drawn inline; whatever the cap drops is STATED as "N more cards from this turn", never hidden. (2) Prose is the answer, the card is evidence. (3) EntityCard has a hard eight-number budget and exactly one colour licence — the verdict word; the price is never coloured because a price is not a direction, and direction always carries a sign as a second channel. (4) The verdict vocabulary is sentiment, never a call: strong bullish / bullish / neutral / bearish / strong bearish (an earlier Buy/Accumulate/Reduce/Sell set was removed for regulatory posture). (5) Two footnote rows per card, never merged: card-specific provenance, then the fixed 'Research and education only. Not investment advice.' (6) Streaming shows one honest line — a pulsing dot, the word "Thinking" (or a real stage label), and a real elapsed second counter; the rotating canned phrases it replaced were removed as a reasoning animation implying work that never happened. (7) Steps, tool chips and references live in ONE collapsed disclosure, and a failure is stated inline in the row, never in a tooltip. (8) Raw tool names never reach the browser — TurnDisclosure applies `prettyTools` itself and an unmapped tool degrades to the vague "Market data", never a title-cased raw name.
