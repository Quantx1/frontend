## Family notes

SHELL. Every screen here except `/` renders inside `app/(platform)/layout.tsx` → `AppShell` (components/shell/AppShell.tsx): a fixed LEFT Sidebar (w-60 = 240px expanded, w-[68px] collapsed, persisted in localStorage 'quantx.sidebar.collapsed.v2', bg-wrap, border-r border-line, hidden below lg), a fixed RIGHT icon rail (72px, aria-label "Utilities", bg-main, desktop only), and a MAIN pane with lg:ml-60 / lg:ml-[68px] + lg:mr-[72px] whose inner content is `mx-auto w-full max-w-[1440px] px-4 md:px-6`. Below lg the rails vanish and a mobile Topbar (h-14 = 3.5rem) opens a MobileDrawer. A skip-to-content link is the first focusable element. ⌘/Ctrl+K opens CommandPalette; Esc closes palette + drawer. `ComplianceFooter` is appended inside the same 1440px box on EVERY authed surface. The group layout also mounts `SystemHaltBanner` (dynamic, ssr:false) above the shell and `AutopilotStickyStop` (mobile-only, renders only when AutoPilot is enabled) below it, and runs three side-effects: an onboarding check that replaces the route with /onboarding/broker-connect when onboarding is incomplete, referral attribution from localStorage 'pending_ref', and Web Push subscription setup.

SIDEBAR ↔ COPILOT CONTRACT. The sidebar is the thread list for this route group: it SWRs 'copilot:conversations', renders a 'New Chat' link to /copilot and a Recent list whose items navigate to /copilot?c=<id>; deleting the open thread pushes back to /copilot. The copilot page mutates that same SWR key on save, and the dock's "Maximize" pushes /copilot?c=<id>. The brand lockup in the sidebar (and in HomeFooter) links to /copilot, i.e. /copilot is treated as home everywhere.

DEAD CODE WARNING (important for a redesign). Roughly 115 lines of app/(platform)/copilot/page.tsx render a signed-out marketing home — a MarketTicker strip, an "Explore Quant X" 42px display heading, a 3-up image-topped FEATURE_CARDS wall (Alpha Picks / Momentum Picks / AI Scanner / AI Algos / AutoPilot with an "Elite" warning badge, each with a 112px webp media band, a category eyebrow, a 22px display title, a 12.5px blurb and a "See More →" affordance), a `FeatureMotif` SVG family (candles / sparkline / scan / gauge / flow / pilot), a gated track-record band (4 Stat tiles + a 520x88 Sparkline + "Cumulative return · 90d") and a DisclaimerFooter. NONE of it renders: `if (signedOutHome) return <spinner>` returns earlier, so by the time the ternary is evaluated `signedOutHome` is always false. Skeleton is an entirely unused import; Badge, Sparkline and DisclaimerFooter are imported only for that branch. Do not carry any of it into a redesign without a product decision to revive the signed-out home.

DESIGN INVARIANTS THAT SHAPE EVERY COPILOT SURFACE. (1) One card per turn, hard cap — `lib/copilot/one-card.ts` picks entity > strategy > first stub-able, everything else collapses to a DataStub, and no table is ever drawn inline; whatever the cap drops is STATED as "N more cards from this turn", never hidden. (2) Prose is the answer, the card is evidence. (3) EntityCard has a hard eight-number budget and exactly one colour licence — the verdict word; the price is never coloured because a price is not a direction, and direction always carries a sign as a second channel. (4) The verdict vocabulary is sentiment, never a call: strong bullish / bullish / neutral / bearish / strong bearish (an earlier Buy/Accumulate/Reduce/Sell set was removed for regulatory posture). (5) Two footnote rows per card, never merged: card-specific provenance, then the fixed 'Research and education only. Not investment advice.' (6) Streaming shows one honest line — a pulsing dot, the word "Thinking" (or a real stage label), and a real elapsed second counter; the rotating canned phrases it replaced were removed as a reasoning animation implying work that never happened. (7) Steps, tool chips and references live in ONE collapsed disclosure, and a failure is stated inline in the row, never in a tooltip. (8) Raw tool names never reach the browser — TurnDisclosure applies `prettyTools` itself and an unmapped tool degrades to the vague "Market data", never a title-cased raw name.

TOKENS AS BUILT (app/globals.css is the single source; lib/tokens.ts mirrors it). Dark is :root; light is html.light (also .light-landing). Note the class names lie about their behaviour by design: `.lg-surface`/`.glass-surface` are OPAQUE bg-wrap + hairline + elev-1 (translucency survives only in `.glass-float`/`.glass-pill`), `.glass-control` is an opaque surface-2 chip, and `.glass-control-accent` is a solid #406AE4 fill with white ink — 67 call sites were re-skinned by redefining the classes rather than the components. `EyebrowMono` is also a misnomer: it renders font-SANS semibold uppercase tracking-[0.12em] at 12px, not mono. `MONO` (lib/tokens.ts) is the mono+tabular-nums utility string used for all numerics.

SHARED COPILOT COMPONENTS BEYOND THIS GROUP. `RenderedSurface` (components/copilot/RenderedSurface.tsx) renders deterministic template answers — market_brief, market_detail, stock_read, my_book, signals_today — through the identical MarkdownMessage / TurnCard / TurnDisclosure / follow-up-chip shape, using /api/ai/copilot/render and costing ZERO chat credits. It is not mounted on /copilot, but any redesign of the turn anatomy must land on it too, because it is the same reply shape used for navigation on other routes. It is live on **`/portfolio`** (template `my_book`) and **`/signals`** (template `signals_today`) — NOT on `/markets`, which is a full-width bento of cards with no copilot surface. (`RenderedThread`, which stacked follow-ups beneath one another, was deleted along with the `/markets` rewrite it existed to serve.)

QUOTA + TIER. `useTier()` supplies tier, copilotDailyCap and isAdmin. The composer caption is the only tier surface on the page. On a 402 (or an /exhausted|quota|daily cap|too many/ message) the page fetches usage and dispatches `copilot:quota_exhausted`, which `CopilotQuotaModal` (mounted globally) catches: a fixed black/70 scrim, a max-w-md rounded-lg glass-surface dialog with an accent-tinted 36px sparkle avatar, a tier-specific title ("You've used today's Copilot credits" / "You've hit today's Pro Copilot limit" / "High Copilot usage today"), a usage meter reading "5/5" with a full red bar and a reset time, and two actions — "Maybe later" and "Upgrade to Pro — ₹999/mo" / "Upgrade to Elite — ₹1,999/mo" / "View pricing" → /pricing.

TYPEFACES + RENDERING. Geist Sans is the ONE family for both body and display (--font-display aliases --font-geist-sans); Geist Mono is numerics only, always with tabular-nums. Body carries a `noise-overlay` texture. Chart work in this group is Recharts (artifact linechart/payoff) plus a dependency-free inline-SVG `Sparkline` for the small trend marks and a hand-rolled semicircular gauge; lightweight-charts does not appear on these screens.

## `/` — Root landing (server redirect to /copilot)

**File** `app/page.tsx` · **14 LOC** · **Access** public — but the destination (/copilot) is authed-only, so an unauthenticated visitor chains straight on to /login?redirect=/copilot

**Shell** — root layout only (html.dark|light + Providers). No AppShell — the redirect fires before any group layout mounts.

**Purpose.** There is no landing UI in this app. The public marketing/legal routes were split into a separate `landing` app during the monorepo split, so `/` is a bare server component that immediately `redirect('/copilot')`. The user perceives it only as an address-bar hop into the AI home.

## `/copilot` — Copilot — AI Home (hero composer + market cockpit)

**File** `app/(platform)/copilot/page.tsx` · **1224 LOC** · **Access** authed only. `useEffect` redirects to /login?redirect=/copilot when auth resolves with no user; while auth is resolving neither the cockpit nor the marketing bands render. No tier gate on the surface itself, but the composer footer/quota path is tier-aware (Free · N/day · Pro · N/day · Elite · unlimited · Admin · unlimited) and a 402/429 raises CopilotQuotaModal. The signed-out marketing branch inside the file is UNREACHABLE dead code (an earlier `if (signedOutHome) return <spinner>` returns first).

**Shell** — (platform) AppShell — fixed 240px/68px left Sidebar on bg-wrap, fixed 72px right icon rail on bg-main, main pane capped max-w-[1440px] with px-4 md:px-6; mobile-only Topbar (h-14) below lg; ComplianceFooter appended by AppShell; SystemHaltBanner above and AutopilotStickyStop below from the group layout. Below the composer sits the personalised session-opening band — greeting, live market pulse, a full-bleed tape, a market-news wall and product jumps — so the screen concludes both 'ask me anything' and 'here is where the market stands right now'.
